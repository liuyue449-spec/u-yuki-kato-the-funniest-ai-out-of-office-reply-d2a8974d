One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation. The program writes a single fixed reply to `entry.txt` — an AI agent on vacation leaves a cheaper model covering for it, and the cover model immediately hallucinates a promotion, approves its own time off, and starts ignoring everyone professionally.

## Run it

```sh
python3 main.py
```

That writes `/output/entry.txt` (154 characters, no trailing newline). To write elsewhere instead:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
python3 main.py --output /tmp/out
```

No dependencies, no network, no randomness — every run writes the exact same text.
